## What is here and what is not

These pages are public, so they carry public-source material only: exchange
documentation, published research, live API behaviour, and figures anyone can
reproduce. Anything touching private repositories, internal code review, or
credentials stays in the relevant private repository instead.

Where a page states a measurement, it says how confident it is and when it was
taken. Several of the numbers move.
